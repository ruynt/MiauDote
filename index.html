Sobre o projeto

Conectando animais a novos lares

O MiauDote é uma plataforma desenvolvida para divulgar animais disponíveis para adoção, facilitando o contato entre adotantes e responsáveis.

O projeto prioriza uma interface simples, acessível e responsiva, aplicando boas práticas de HTML5, CSS3 e Engenharia de Interface.
